# Introduction
[Reclaim Protocol](https://reclaimprotocol.org) lets you verify information about a user from any website. If a website has information behind a login that you want to verify, Reclaim Protocol can verify that. 

Some examples
- Verify a user's salary at their current job using their employer's HR portal
- Verify a student's graduation details using their university's student portal
- ... as long as a user can login, we can verify the information behind that login

# Flow of control 
1. User taps a button to initiate verification on your app/website
2. User asked to login into the portal from which the required information can be verifed
3. After successfully logging in, the user is asked to wait for a few seconds until verification is completed. This step can take between 2 to 30 seconds.
4. The verification is sent back to your app/website's backend

# Integrate now - it's just a prompt copy paste
1. Head over to [build.reclaimprotocol.org](https://build.reclaimprotocol.org). 
2. Enter the prompt of what you want your users to prove.
3. Copy paste the prompt into Codex, Claude Code or any agent you are using, and instruct to integrate a Reclaim Protocol verification. Not using an agent (boo!)? [Contact us for help](mailto:support@reclaimprotocol.org).

# Is it secure and compliant?
**Short answer, yes.**

Reclaim Protocol uses Zero Knowledge Proofs and Trusted Execution Environments to make sure the user's data is kept private. No information other than what they are proving is leaked to either us or the customer integrating Reclaim Protocol.

Compliance
- SOC2 Type 2
- ISO 270001
- GDPR Ready
- NIST 500

You can request these certifications and questionnaires - [contact us](mailto:admin@reclaimprotocol.org)

You can see a detailed breakdown of each of our security commitments on our [trust package](https://trust.reclaimprotocol.org).
